# DDNet E-450 Custom

Кастомная сборка DDNet под слабый ПК (AMD E-450, 2 ГБ ОЗУ, Windows 10 64-bit).

**Что это:** официальный клиент DDNet 20.2.1 + свой лаунчер с профилями производительности и бесконечной ротацией серверов/карт. Не движок с нуля — движок DDNet используется официальный, иначе за один вечер это не сделать. exe собирается в GitHub Actions.

## Что реально на твоём железе

- E-450 (1.65 ГГц, 2 ядра) + Radeon HD 6320 — очень слабая система.
- 100+ FPS реально только в 1024x576 / 800x450, низкие детали, без звука, без браузера в фоне.
- 1920x1080 + красивые эффекты = 20–40 FPS. Физики не обмануть.
- Профиль `beauty1000` красивее, но минус 10–20 FPS.

## Что внутри

- `profiles/fast.cfg` — максимум FPS: 120 Гц обновление, vsync выкл, высокую детализацию выкл, звук выкл, skins не качаются.
- `profiles/beauty1000.cfg` — «красивый» вид без неона: стандартный UI и цвет tee, имена/эффекты, зум 14.
- `infinite-levels.txt` —autogenerated список всех официальных серверов DDNet (сотни карт). Лаунчер берёт случайный адрес и подключает → бесконечная смена уровней.
- `launcher/launcher.c` — лаунчер (C, без STL, собирается быстро): собирает cfg, запускает DDNet с приоритетом выше обычного, после выхода подключает к следующему серверу. Локально собранный `DDNet-Custom-Launcher.exe` уже лежит в `DDNet-Portable`. `launcher/launcher.cpp` оставлен как запасная C++-версия.
- `.github/workflows/build.yml` — сборка exe + архива в GitHub Actions.

## Как получить exe

1. Создай GitHub-репозиторий, залей содержимое этой папки (включая скрытую `.github`).
2. Открой вкладку **Actions** → **DDNet E-450 Custom Build** → **Run workflow**.
3. После завершения скачай artifact `DDNet-E450-Custom` (или релиз, если поставил галочку publish_release).
4. Распакуй на ПК в любую папку, запусти `START.bat`.
5. Красивый режим: `DDNet-Custom-Launcher.exe --beauty`.
6. Чтобы лаунчер не запустил следующий уровень после выхода из игры: запусти `STOP.cmd`, потом закрой DDNet.

## Настройки, которые реально дают FPS

В DDNet нет `gfx_maxfps`. Лимит задаётся парой `cl_refresh_rate` + `gfx_refresh_rate`. Это учтено в профилях.

## Если 20.2.1 не запустится на старом драйвере

Открой `.github/workflows/build.yml`, измени `DDNET_VERSION: 20.2.1` на `19.8.2` или `18.9.1` и запусти workflow заново. Список версий — на ddnet.org/downloads.

## Важно

Никаких токенов в репозиторий не вставляй. Workflow использует встроенный `GITHUB_TOKEN`. Tokens из настроек я не использовал.
